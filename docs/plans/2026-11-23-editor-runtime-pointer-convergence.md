# 编辑区指针与选区迁移

本记录对应《中长期架构演进计划》的 1.2。

## 已接入共享宿主

- 绘制帧按活动标签记录源码左边距或插件内容矩形。共享命中测试、插件滚动和输入法候选窗使用同一组几何。覆盖产品提供的源码起点和插件原点的回归用例在修复前均失败。
- 多击历史由活动编辑器的 `EditorRuntime` 持有。Textora 按截断后的整毫秒判断 500 ms 窗口，失焦时保留点击历史。Notora 按精确时长判断，失焦时清空历史。两端均按相邻两次按下的位置判断 5 个物理像素的距离，最多三击。
- 只读预览的按下、拖选和释放进入 `handle_pointer_event`。字词和行范围由视图提供，拖选起步阈值为 5 个逻辑像素。回归覆盖 1× 至 3× 缩放下的起拖行为、双击选词、三击选行和释放空选区。
- 可编辑插件和画布也进入 `handle_pointer_event`。Textora 保留视觉光标亲和性、初始语义范围、双击选词和两阶段字节命中。文本拖选仍以 5 个逻辑像素起步，画布对象拖拽仍以 5 个物理像素起步。Notora 保留按初始范围扩展字词或行的策略。
- 宿主采用互斥枚举保存文本选区和画布拖拽。画布拖拽会话记录发起标签，失焦、切换标签、切换视图时由宿主取消，并仅在有效放下时应用编辑事务。Textora 的窗口层读取宿主捕获状态。
- 纯文本指针也走共享入口。Textora 的视觉行策略保留折行落点、空行和首次拖动确定的词行锚点。Notora 沿用字节命中与初始选区范围。窗口层转发焦点、物理坐标和控件的光标优先级，编辑区命中、手势和光标由宿主处理。

## 验证

迁移后的 33 项源码指针测试运行共享实现。Textora 的入口级回归通过鼠标按下、拖动、释放验证选区和折行落点。标签切换回归核对原标签收到一次取消通知且正文保持原样。

完整的 Textora 宿主迁移切片通过 `./scripts/verify.sh`。
