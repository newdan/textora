# MMF 源码节点索引

解析器在构造只读 `Tree` 时建立完整的 DFS 先序索引。索引记录父节点、同级序号和子树的结束位置。根节点通过共享引用访问，调用者可直接查询节点、遍历子树或跳到同级节点。折叠节点保留源码序号，布局用独立的可见节点序号，因此折叠不会改变编辑事务的目标。

渲染、命中测试、拖拽、键盘导航和源码编辑复用同一索引。解析器将全局 TOML 块和主题值的字节范围保存在 `Tree`，主题编辑沿用解析时的范围和原文换行符。`MindmapFocus` 由 MMF 模型定义，画布和视图使用同一类型。
