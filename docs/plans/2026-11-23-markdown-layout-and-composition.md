# Markdown 排版与输入法投影

`BlockViewEngine` 持有文档排版和可选的预编辑替换状态。替换状态管理临时源码的排版缓存及其字节偏移映射。渲染、命中和光标查询直接使用当前显示的排版，光标与选区交给文档前映射回原始字节位置。提交或取消预编辑后，文档继续使用自身的排版状态。

`ProjectedText` 保留字素边界及源码锚点。行内样式使用 `StyleSpan`，只读布局直接沿用已有样式，编辑布局按已展开的源码和预编辑内容调整样式范围。

块排版按段落、列表、引用、代码和其他块类型分派。绘制按块类型以及普通行、临时定位行和精确定位行分派。Enter 分类器按解析事件收集容器上下文，再解析列表、段落、代码和表格中的光标位置。

## 验证

- `cargo test -p textora-markdown --lib` 通过 1,355 个库测试。
- `cargo test -p textora-markdown --lib --no-default-features` 通过 1,235 个库测试。
- 输入法专项通过 37 个测试，包含取消、提交、组合字符、选区替换和命中映射。
