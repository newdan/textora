# Textora 设置与主题所有权

本记录对应《中长期架构演进计划》的 1.4。

- `EditorRuntime` 持有 Textora 当前设置和解析后的主题。界面、编辑器、设置面板和持久化读取宿主。构造时直接将设置与主题交给宿主。
- 菜单、设置面板和文字缩放通过 `edit_settings` 提交设置。一次有效提交生成一个设置版本并返回持久化效果。重复提交相同值时保留版本和排版缓存。设置面板仍可显式重试失败的写盘。
- 主题模式变化时使用当前系统外观重新解析主题。系统外观事件只在跟随系统时更新主题。退出时的窗口几何保存保留磁盘上的编辑器设置字段。
- Chrome 布局继续通过 `UiMetrics` 将逻辑单位换算为物理像素。边界测试覆盖通过宿主设置入口读取逻辑尺寸的情况。

设置相关的 91 项测试通过。完整的 Textora 宿主迁移切片通过 `./scripts/verify.sh`。
