# Notora 设置界面优化

目标：改善窄窗口可用性，避免刷新丢失编辑状态，让输入规则与失败反馈清晰可理解。

修改 Notora 设置视图与回归测试，并在共享表单中增加纯布局接口；设置模型和持久化协议不变。

## 子任务

1. 布局：根据表单实际可用宽度切换双列或上下排列，同步调整行高；主题按钮在可用空间内分配宽度；缩短重叠的说明文案。涉及 `notora_settings_view.rs` 和回归测试文件。
2. 状态：保存状态变化只更新反馈；产品设置刷新时保留未提交文本和滚动位置；分类切换重置滚动但保留草稿；浮点显示保持原始精度。
3. 反馈：明确 Enter 提交规则；校验错误标明字段和范围；错误文字与重试按钮分区裁剪。
4. 共享布局接口：`FormView::set_row_height_logical` 委托 `FormSection` 更新行高，在下一次布局生效。涉及 `form/view.rs`、`form/section.rs` 和 Notora 视图三个文件。缩放只更新几何，不重建文本框，从而保留光标、选区与输入法状态。

## 验证

先新增回归测试并确认失败，再实施修复。覆盖保存反馈、其他字段更新、滚动保持、窄屏与双倍 DPI、数值校验和浮点精度。

执行 `cargo test -p notora-app notora_settings_view -- --test-threads=1`、`cargo fmt --all -- --check` 及 `./scripts/verify.sh`，记录环境限制与结果。
