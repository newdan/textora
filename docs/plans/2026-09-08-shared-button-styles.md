# notora / textora 共享按钮样式修复

## 目标与接口

普通操作按钮统一使用主题主文字、控件背景/边框、共享圆角及字号。默认、悬停、按下、选中、禁用状态和全局透明度只在 ui 层解析。保留导航、分段选项和无底色图标按钮的视觉角色。

在 `ui::button` 公开 `ButtonVisualState` 和共享 `ButtonStyle` 构造器、绘制方法。产品层仅传入矩形、标签、图标、状态和语义主题，不引入任何 ui → app 依赖。

## 子任务

1. **共享样式与绘制**（button.rs、button/style.rs、theme/settings.rs）：把样式构造从 Button 拆出，集中 Action / Category / Segmented / Ghost 角色；用枚举解析互斥视觉状态，共享背景、边框和文字透明度处理。增加禁用/悬停/按下绘制回归测试，先验证失败再修复。
2. **共享操作组件**（split_button.rs、status_state.rs）：迁移分段按钮和空状态按钮；分段按钮保留区域裁剪、独立主操作/菜单事件和菜单打开反馈。验证普通按钮与分段按钮深浅主题、多 DPI、透明度绘制一致。
3. **textora 侧栏**（sidebar/state.rs、sidebar/widget_tests.rs）：打开按钮改用普通操作样式，与新建按钮一致；保留侧栏动画透明度。先加实际绘制对比测试再迁移。
4. **notora 操作按钮**（render.rs、render/buttons.rs）：移除上一轮局部颜色/圆角修复，改用共享绘制入口；导航折叠图标也使用明确的共享角色。将手绘按钮指针反馈拆入 buttons.rs，保留键盘/IME 透传和模态遮挡。现有工具栏文字/边框回归测试持续通过。
5. **设置页共享角色**：分别迁移 ui 设置页、textora 设置导航/同步页、notora 设置页，每个子任务最多修改三个文件；删除重复样式常量和混色函数，验证禁用按钮及选中分段的颜色和交互。
6. **文档和验证**：更新 `docs/specs/ui-control-tokens.md`；运行 `./scripts/verify.sh`，编译 notora 和 textora；只读审查确认无遗漏的同类按钮。

## 验收

- 同角色按钮使用相同的颜色、边框、圆角、字号和状态规则。
- 文本、图标、背景、边框各自只应用一次 DPI/全局透明度，禁用边框也正确降透明度。
- 分段菜单、键盘/无障碍操作、导航选中状态正常。
- 深浅主题、1x/1.5x/2x DPI、半透明状态的绘制回归及完整仓库检查通过。
