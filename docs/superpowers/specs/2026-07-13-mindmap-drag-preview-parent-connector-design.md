# Mindmap 拖拽预览父节点连接线设计

## 目标

拖拽节点时，无论预览位置对应同级排序还是跨级移动，只要目标合法，都从目标位置的真实父节点绘制一条临时连接线到预览卡片。目标位置存在排序插入线时，连接线与插入线同时显示。

## 数据流

`MindmapView::calculate_drag_preview()` 继续负责解释树结构和移动目标。它根据最终的 `MoveSubtreeTarget` 与锚点节点确定目标位置的真实父节点，并将父节点卡片右侧中点写入 `CanvasDragPreview::guide_to`。预览卡片左侧中点继续由 `guide_from` 表示。

`mmf::canvas` 只消费 `guide_from`、`guide_to` 和 `insertion_line`：存在 `guide_to` 时绘制临时连接线；存在 `insertion_line` 时绘制排序插入线。渲染层不反查树关系，也不访问应用状态。

目标父节点规则：

- `BeforeSibling`、`AfterSibling`：使用锚点节点的真实父节点。
- `BeforeChild`、`LastChild`：使用目标父节点本身。
- 无法确定父节点或目标非法：不绘制合法连接线，保留现有无效拖拽反馈。

## 边界与职责

- 不改变拖拽落点判定、节点移动事务或源节点透明度。
- 不新增 UI 层对 Markdown 树模型的依赖。
- 不改变现有连接线颜色、粗细和曲线路径算法。
- 根节点不可被拖动的既有约束保持不变。

## 测试

先增加失败测试，覆盖从其他层级拖入某父节点的子节点序列中间：

- 预览合法。
- `guide_to` 等于目标真实父节点卡片的右侧中点。
- `insertion_line` 同时存在。

再运行相关拖拽预览与渲染测试，确保已有子节点落点、同级排序和无效拖拽反馈不回归。
