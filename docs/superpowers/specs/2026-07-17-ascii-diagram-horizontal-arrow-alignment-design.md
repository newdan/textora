# ASCII 图水平箭头对齐设计

**日期：** 2026-07-17  
**状态：** 已确认

## 目标

Markdown fenced code block 被识别为 ASCII 图后，水平连接符 `────────→` 与
`←────────` 必须显示为视觉连续、处于同一水平中心线的几何连接线。

## 根因

当前框线字符 `─` 按行框的垂直中心绘制几何矩形，而 `→`、`←` 仍按字体基线绘制。
字体字形的视觉中心不保证等于行框中心，因此箭头头部会相对箭身产生垂直偏移。

## 方案

- 仅在 ASCII 图预览渲染路径中识别紧邻 `─` 的连续连接箭头：`→` 的左邻格
  必须为 `─`，`←` 的右邻格必须为 `─`。正文中的独立箭头继续按文本渲染。
- 使用 `DrawList` 的矩形与三角形绘制水平箭头，箭身中心严格复用框线的
  `line_top + line_height / 2`。
- 箭头保持原单元格的网格位置和分配宽度，不修改源 Markdown、布局列数、复制内容或编辑态。
- 活动代码块继续走既有普通文本渲染路径；竖向箭头和其他字符不在本次范围内。

## 测试

先新增失败的渲染回归测试，验证：

1. WPS 架构图中的右箭头使用几何三角形，而非 `TextLayout` 字形。
2. 箭头三角形的垂直中心与同一行 `─` 的几何中心一致。
3. 左箭头采用相同规则，箭头方向正确。
4. 既有 ASCII 图与 Markdown 测试继续通过，并完成 `textora-markdown` 编译检查。

## 验收标准

预览中的 `────────→` 和 `←────────` 箭身与箭头头部无上下错位，连接处连续；
源码、编辑态与非 ASCII 代码块行为不变。
