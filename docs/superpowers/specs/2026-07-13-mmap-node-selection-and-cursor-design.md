# mmap 节点选择、编辑与鼠标光标

## 目标

统一 mmap 画布上的点击、拖动与鼠标光标语义，避免首次点击节点时误触发拖动。

## 交互约定

1. 点击节点卡片的非文字区域：选中该节点。
2. 点击节点标题文字：将文档光标定位到对应标题，进入文字编辑。
3. 只有鼠标按下前该节点已经处于“节点选中且非编辑”状态，且按下点位于卡片非文字区域时，超过既有拖动阈值后才开始拖动节点。
4. 在标题文字上按下并移动始终保持文字选择/编辑语义，不创建节点拖动会话。

## 光标语义

| 命中区域或状态 | 光标 |
| --- | --- |
| 节点标题文字 | `Text` |
| 未选中的节点卡片非文字区域 | `Pointer` |
| 已选中、非编辑节点的卡片非文字区域 | `Move` |
| 画布空白或绘制区域外 | `Default` |

## 设计

在 app 的鼠标分发层，鼠标按下时先读取当前文档选区，判断命中的 `SourceObject` 范围是否已经被完整选中；随后仍立即应用该次点击的选择。拖动会话保存此“按下前已选中”的事实。指针移动达到现有阈值时，只有该事实为真才向插件发起画布拖动请求。

鼠标移动时，app 通过既有 `HitTestEditTarget` 查询读取 mmap 的语义命中结果，并结合当前选区计算光标图标。这一逻辑仅作用于自绘且可编辑的 mmap 画布，其他编辑器和预览插件保留现有光标策略。

## 边界与错误处理

- 源码同步或命中查询不可用时，保持现有默认文本光标策略，不阻断输入。
- 拖动过程中维持现有拖动预览与取消/放下处理；没有资格的会话不会向插件发送开始、更新或放下请求。
- 不修改 mmap 渲染、布局、文档解析或编辑事务语义。

## 测试

- 在 app 鼠标分发测试中验证：首次按住未选中卡片移动不会发起画布拖动；按住已选中卡片移动会发起拖动。
- 在事件测试中验证：mmap 标题、未选中卡片、已选中卡片、空白区域分别产生 `Text`、`Pointer`、`Move`、`Default` 光标动作。
- 运行对应 app 单元测试和 `cargo check -p edit-plus-app`。
