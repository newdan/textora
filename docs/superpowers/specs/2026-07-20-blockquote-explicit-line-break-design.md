# 引用块显式行标记换行

## 背景

Markdown 预览目前将所有 `SoftBreak` 转为空格。因此连续使用 `>` 的结构化引用会被合并为同一视觉行，且仅在宽度不足时自动折行。

## 目标

在同一引用块中，下一行具有显式引用标记 `>` 的软换行必须保留为视觉换行。每个显式引用行仍属于同一 `BlockQuote`，共享引用背景、左侧竖线和块间距。

## 范围

- 仅影响引用块内的软换行。
- 仅当软换行后的源码行以引用标记 `>` 开始时生效。
- 普通正文软换行和引用块的懒续行继续按现有 Markdown 语义显示为空格。
- 行尾两个空格、反斜杠和 HTML `<br>` 产生的硬换行不改变。
- 嵌套引用同样按显式引用行处理。

## 设计

解析阶段根据软换行的源码区间检查其后的物理行是否有显式 `>` 标记，并将结果传递给构建阶段。构建阶段遇到该类引用软换行时，把当前文本行提交到当前段落；其他 `SoftBreak` 仍追加一个空格。

为避免把行提交后丢弃，普通硬换行也应使用同一个“提交到当前块”的路径。

## 验证

添加回归测试覆盖：

1. 连续四行 `>` 引用按四个布局行输出；
2. 引用块中的懒续行仍合并为空格；
3. 普通段落软换行仍合并为空格；
4. 强制换行保留两个视觉行。
