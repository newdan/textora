# 紧凑设置表单设计

## 目标

缩小设置浮层及其表单控件，消除卡片内容与边框贴合的问题，使三个设置分类在保持可读性和响应式布局的同时拥有更紧凑的视觉密度。

## 范围

- 设置浮层的默认首选尺寸从 900×640 缩小到 680×480 逻辑像素。
- 设置分类侧栏宽度调整为 152 逻辑像素。
- 右侧表单在四周保留 16 逻辑像素内边距。
- 字体、字号、行高比例与 Tab 宽度四个文本框统一为 200×32 逻辑像素，并在控制列左对齐。

不改变通用表单行高、开关尺寸、分类切换、输入校验、持久化或窄窗口下的纵向响应式布局。

## 布局

设置页继续由左侧分类导航和右侧 `FormView` 组成。`SettingsView` 只负责将其右侧可用区域按 16 逻辑像素收缩后交给 `FormView`，不修改 `FormView` 或 `FormSection` 的通用几何规则。

每个文本框将放入固定宽度的行内容器。表单行仍按既有规则分配控制列，行内容器仅占用其中的前 200 逻辑像素；因此宽窗口不会拉伸输入框，窄窗口仍由现有 `FormRow` 纵向布局处理。

浮层继续使用既有居中、最大尺寸比例与最小窗口边距策略。若窗口不足以容纳首选尺寸，既有 `OverlayLayout` 约束优先，表单的滚动与响应式布局保持可用。

## 测试与验证

- 应用层测试断言设置浮层的首选尺寸为 680×480。
- 设置页布局测试断言分类栏宽度为 152，表单区域四周保留 16 内边距。
- 设置页测试断言四个文本输入控件的布局宽高为 200×32，且不占满控制列。
- 运行对应 UI 与应用测试、`cargo fmt --check`、`cargo check -p edit-plus-app`，最后运行 `./scripts/verify.sh`。
