# 新建 MMAP 默认空根节点设计

## 目标

通过“新建 MMAP”创建文档时，画布默认显示一个标题为空的根节点，并允许用户无需点击节点即可直接输入标题。

## 设计

新建文档的初始内容属于应用层的文档创建职责。`Workspace` 为不同的 `NewDocumentKind` 提供对应的新建规格；MMAP 的规格除建议文件名和默认插件外，还提供初始源码 `#` 以及初始光标字节位置 `1`。

`#` 是 MMF 解析器已经支持的合法空标题一级节点。其标题范围为零长度区间 `1..1`。将 `DocumentView` 的光标同步到字节 `1` 后，mindmap 插件会从文档状态推导出根节点标题编辑焦点，因此用户可以直接输入。

TXT 和 Markdown 继续使用空文档与字节 `0` 光标。已有文件的加载、空 MMAP 文件的错误语义、MMF 解析器和 UI 层均不改变。

## 状态语义

- 新建 MMAP 的源码为 `#`，建议文件名仍为 `未命名.mmap.md`。
- 默认插件仍为 `mindmap`。
- 初始光标位于空标题范围 `1..1`。
- 初始模板内容不视为用户编辑，文档保持干净；首次输入后再进入脏状态。
- 保存时按现有流程写出当前源码，不增加虚拟节点或保存时转换。

## 测试

在 `workspace` 层增加回归测试，使用真实 `DocumentView` 和插件注册表验证新建 MMAP：

- 完整源码等于 `#`；
- 光标字节位置等于 `1`；
- 文档初始状态干净；
- 建议文件名和默认插件保持不变。
