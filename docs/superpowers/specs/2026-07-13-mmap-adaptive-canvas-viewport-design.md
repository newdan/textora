# mmap 自适应画布、滚动与缩放设计

## 背景

当前 mmap 直接以插件视口左上角作为内容原点，仅维护纵向 `scroll_y`。布局结果虽然已经提供 `total_w` 与 `total_h`，但画布没有内容边距、水平滚动、覆盖式滚动条或独立缩放状态。小型 mmap 因此贴在左上角，大型 mmap 无法完整浏览；渲染、命中、光标与 IME 也缺少可复用的二维视口变换。

本设计为 mmap 建立通用画布视口协议。画布至少覆盖可视区，并根据缩放后的内容包围盒与混合边距自动扩展；内容较小时水平、垂直居中，内容较大时产生对应方向的滚动范围。mmap 使用独立于编辑器字号的缩放比例，并支持以手势中心或鼠标指针为锚点的连续缩放。

## 目标

- 小型 mmap 在插件视口中水平、垂直居中，并保留均衡边距。
- 画布按内容尺寸自动扩展，不引入固定页面边界或无限画布动态扩边。
- 内容溢出时提供按需显示的横向、纵向覆盖式滚动条。
- 保留触控板原始二维滚动增量。
- 支持双指捏合与 `Cmd/Ctrl + 滚轮` 连续缩放。
- 缩放时保持手势中心或鼠标指针下的内容点稳定。
- mmap 缩放独立于全局编辑器字号，并按标签页保存当前会话视角。
- 渲染、命中、光标、IME、文字选择和节点拖拽共用同一正逆变换。
- 建立可供其他自绘画布插件复用的纯数据协议，不让 `ui` 或 `app` 接触 mmap 节点树。

## 非目标

- 不实现带固定纸张边界的有限页面。
- 不实现需要动态扩边的无限画布。
- 不把画布视角写入 `.mmap.md` 或用户配置文件。
- 第一阶段不实现空格加左键拖动画布或鼠标中键拖动画布。
- 不改变 MMF 语法、节点布局算法、节点编辑事务或拖拽排序语义。
- 不为 mmap 增加专用的 app 状态分支或 UI 对节点树的访问。

## 体验约定

### 自适应画布

画布没有可见的纸张边界。主题背景填满整个插件视口，逻辑画布范围只用于确定内容原点、居中位置和滚动范围。

内容包围盒必须覆盖以下视觉元素：

- 所有节点卡片与标题文字；
- 所有连接线；
- 选中态外轮廓；
- 当前节点拖拽反馈可能占用的范围。

当缩放后的内容与两侧边距可以放入视口时，该方向的逻辑画布尺寸等于视口尺寸，内容居中且滚动位置为零。当内容放不下时，该方向的逻辑画布扩展为缩放后内容加两侧边距，并产生滚动范围。

### 混合边距

内容坐标中定义基础边距，屏幕坐标中定义最小边距：

```text
屏幕边距 = max(基础内容边距 × zoom, 最小屏幕边距)
```

基础内容边距跟随内容缩放，表达画布中的空间；最小屏幕边距只跟随 DPI，避免缩小时内容贴近视口边缘。两者都必须通过语义化主题或视口指标字段提供，不得在渲染或事件代码中散落魔法值。

### 初始适配与重置视图

首次打开 mmap 或执行“重置视图”时，按完整内容包围盒计算适配比例：

- 适配比例最大为 `100%`；小型内容保持原始尺寸并居中。
- 自动适配优先不低于 `40%` 的可读下限。
- 如果 `40%` 仍无法容纳完整内容，则保持 `40%`，并在溢出方向显示滚动条。
- 手动缩放范围为 `25%–400%`。

自动适配下限与手动缩放下限职责不同：前者防止首次打开时文字不可读，后者允许用户主动查看全局结构。

### 状态生命周期

每个标签页保存独立画布视角。切换标签页后恢复此前的缩放和平移；关闭标签页后不持久化，重新打开文件时重新执行初始适配。

视角初始化状态使用互斥状态表达，区分“等待首次适配”和“已具有用户视角”，不得用多个布尔字段组合表示。

## 架构与职责

### `ui` 层

`ui` 定义不依赖 app 状态或 mmap 模型的纯数据画布结构与算法：

- 内容包围盒与视口输入；
- 画布视角输入；
- 不可变的视口快照；
- 内容坐标与屏幕坐标之间的正逆变换；
- 混合边距、居中偏移和滚动范围计算；
- 横向、纵向滚动条的纯数据输入与动作；
- 缩放锚点和平移钳制计算。

`ui` 不访问 `DocumentView`、Workspace、Commands、Events 或 mmap 节点树。

### `app` 层

`app` 负责：

- 为每个标签页保存画布视角状态；
- 将滚轮、触控板、捏合和滚动条事件转换成通用画布动作；
- 调用画布插件准备内容指标；
- 使用 `ui` 纯计算解析当帧视口快照；
- 把同一快照交给插件渲染和画布查询；
- 更新滚动条交互状态并请求重绘。

`app` 只认识通用画布指标和动作，不解析 MMF，也不保存节点索引或节点树。

### mmap 插件

mmap 负责：

- 解析文档并生成内容坐标中的布局；
- 报告完整内容包围盒；
- 使用当帧视口快照渲染节点、文字、连线和反馈；
- 使用同一快照完成命中、光标、IME、文字选择和节点拖拽坐标转换。

mmap 移除自有 `scroll_y`。插件不得在通用快照之外再保存另一份滚动或缩放状态。

## 通用画布协议

画布插件采用三阶段数据流：

```text
Prepare：插件准备布局并报告 CanvasContentMetrics
                         ↓
Resolve：app + ui 解析 CanvasViewportSnapshot
                         ↓
Render / Query：插件消费同一份快照
```

### Prepare

画布插件在渲染前完成取得内容包围盒所需的布局，返回纯数据内容指标。非画布插件使用默认空实现，不受此协议影响。

Prepare 必须发生在解析视口快照之前，避免首帧先画在左上角、下一帧再跳到居中的视觉抖动。

### Resolve

app 将以下输入交给 `ui` 的纯计算模块：

- 插件视口矩形；
- 内容包围盒；
- DPI；
- 当前缩放比例和滚动位置；
- 基础内容边距和最小屏幕边距；
- 初始化或保留视角策略。

输出的不可变快照至少包含：

- 内容到屏幕的正向变换；
- 屏幕到内容的逆变换；
- 横纵最大滚动位置；
- 横纵居中偏移；
- 缩放后内容范围；
- 横纵滚动条输入；
- 插件绘制裁剪矩形。

### Render / Query

渲染、命中测试、光标矩形、IME 矩形、文字选择和节点拖拽必须消费同一份快照。调用方不得在插件外额外减去滚动偏移，插件也不得重复应用视口原点。

内容到屏幕的概念变换为：

```text
屏幕坐标 = 视口原点 + 居中或边距偏移 + 内容坐标 × zoom - scroll
```

逆变换必须由同一快照推导，不能在各命中路径中重复实现公式。

## 滚动交互

- 触控板二维滚动保留原始 `x/y` 分量，同时更新两个方向。
- 普通鼠标滚轮默认纵向滚动。
- `Shift + 滚轮` 执行横向滚动。
- 滚动位置始终钳制在当帧合法范围内。
- 某方向不再溢出时，该方向滚动位置归零，内容重新居中。

覆盖式滚动条规则：

- 仅在对应方向存在溢出时参与布局、绘制和命中。
- 不占用或压缩插件内容视口。
- 滚动、拖动或悬停时以清晰状态显示，静止后降低透明度但不完全消失。
- 点击轨道与拖动滑块使用现有通用滚动条动作语义。
- 横纵滚动条同时出现时，右下角保留交互避让区，两个滑块不能相互覆盖。
- 滚动条宽度、最小滑块尺寸和命中热区只跟随 DPI，不跟随画布缩放。

## 缩放交互

支持以下入口：

- 双指捏合连续缩放，以手势中心为锚点；
- `Cmd/Ctrl + 滚轮` 连续缩放，以鼠标指针为锚点；
- 显式“重置视图”重新执行有上限的自动适配。

每次缩放按以下顺序更新：

1. 使用旧快照把屏幕锚点反算为内容坐标。
2. 将新缩放比例钳制到手动缩放范围。
3. 根据新比例重新计算混合边距、逻辑画布与滚动范围。
4. 求出使该内容坐标仍落在原屏幕锚点所需的滚动位置。
5. 将结果钳制到新的合法滚动范围。

节点、文字、连接线、选中反馈和内容基础边距整体参与缩放。最小屏幕边距、滚动条和交互热区不参与画布缩放。

## 视角稳定策略

### 窗口与 DPI 变化

- 首次取得有效布局时执行自动适配。
- 用户已经平移或缩放后改变窗口尺寸，保留视口中心对应的内容点，不重新自动适配。
- DPI 变化时根据逻辑指标重新解析快照，不把已有滚动位置再次乘以 DPI。

### 内容布局变化

- 编辑节点导致内容包围盒变化时，优先保持正在编辑或选中的节点屏幕位置。
- 没有焦点节点时，保持变化前视口中心对应的内容点。
- 更新后的滚动位置必须按新范围钳制。
- 内容缩小并消除某方向溢出时，该方向重新居中。

该策略防止输入、IME 预编辑或节点标题变宽时，当前节点突然跳离视口。

## 裁剪与坐标单位

- mmap 布局使用内容坐标。
- `zoom` 是无单位比例。
- DPI 负责逻辑单位到物理像素的转换。
- 最终绘制严格裁剪在插件视口内，不得覆盖标签栏、状态栏或侧边栏。
- 内容基础边距先换算到物理内容单位，再参与缩放。
- 最小屏幕边距和滚动条指标按 DPI 换算，但不乘 `zoom`。

## 异常处理

- 非法 MMF 显示现有错误画布，隐藏横纵滚动条，不覆盖当前标签页已保存的用户视角。源码修复后恢复此前视角并按新范围钳制。
- 空内容包围盒按单点内容处理，以 `100%` 居中显示，不产生滚动范围。
- 内容指标包含 `NaN` 或无穷值时，拒绝该帧指标并使用无滚动的安全视口；无效值不得写回标签页状态。
- Prepare 暂时无法取得布局时保持等待初始化状态，不使用过期内容尺寸执行首次适配。
- 缩放或滚动期间发生源码刷新时，先取得最新内容包围盒，再按焦点节点或视口中心策略恢复视角。

## 阶段拆分

### 子任务一：通用画布数学模型

在 `ui` 中建立纯数据视口输入、视口快照、正逆变换、混合边距、居中和滚动范围计算。先完成纯函数测试，不接入 mmap。

### 子任务二：app 画布控制器与滚动条

为标签页增加互斥的画布视角状态，接入二维滚动、横纵覆盖式滚动条、缩放锚点和窗口变化。普通编辑器与阅读视图保持原行为。

### 子任务三：mmap 坐标体系迁移

mmap 移除自有纵向滚动，报告完整内容包围盒；渲染、命中、光标、IME、文字选择和节点拖拽统一迁移到通用视口快照。

### 子任务四：手势与集成验证

接入双指捏合与连续缩放，完成滚动条显隐、DPI、窗口调整、内容变化和标签页切换验证，并执行完整验证脚本。

每个子任务涉及的提交必须先通过对应编译与测试。不得在一个未通过编译的阶段上继续叠加后续阶段。

## 自动化测试

### `ui` 纯计算

- 小内容在不同宽高视口中水平、垂直居中。
- 仅横向、仅纵向和双向溢出的画布范围。
- 基础内容边距与最小屏幕边距在不同缩放比例下正确切换。
- 负坐标内容包围盒仍能正确居中和滚动。
- 初始适配不超过 `100%`，并优先不低于 `40%`。
- 手动缩放钳制在 `25%–400%`。
- 缩放前后锚点对应的内容坐标保持一致。
- 窗口调整后视口中心稳定，滚动位置正确钳制。
- 内容缩小后滚动范围归零并重新居中。
- 无效浮点内容指标不会产生无效快照。

### 滚动条组件

- 横纵滑块比例反映可视范围与逻辑画布范围。
- 点击轨道和拖动滑块正确映射滚动位置。
- 单方向溢出时只显示对应滚动条。
- 双向滚动条正确避让右下角交汇区域。
- 淡化状态不改变既有滚动范围或滑块位置。

### app 事件与状态

- 触控板二维增量同时更新横纵滚动位置。
- 普通滚轮与 `Shift + 滚轮` 路由到正确方向。
- 捏合和 `Cmd/Ctrl + 滚轮` 只在活动画布视图中更新画布缩放。
- 非画布视图保留现有编辑器缩放与滚动行为。
- 不同标签页的画布视角互不污染。
- 切换标签页恢复视角，关闭并重新打开后重新初始适配。
- 窗口与 DPI 变化遵循视角稳定策略。

### mmap 集成

- 非 `100%` 缩放并双向滚动后，节点卡片和标题命中仍准确。
- 光标、IME 候选窗、文字选择与渲染位置一致。
- 节点拖拽来源、预览、目标反馈和放下位置一致。
- 编辑或预编辑导致布局变化时，活动节点屏幕位置保持稳定。
- 非法 MMF、空内容和异常内容指标不产生滚动条或崩溃。

## 人工验收

- 小型 mmap 首次打开后自然居中，四周留白均衡。
- 大型 mmap 以可读比例打开，溢出方向出现覆盖式滚动条。
- 双指缩放过程中，手势中心下的节点没有明显漂移或跳帧。
- 二维触控板滚动方向自然，斜向滚动不会退化为单轴。
- 滚动条不挤压内容，不遮挡标签栏、状态栏或侧边栏。
- 编辑节点导致布局变化时，当前节点不会突然跳离视口。
- Retina 与普通 DPI 下的边距、滚动条、命中和光标位置一致。

重大修改完成后运行：

```bash
./scripts/verify.sh
```

## 成功标准

完成后，mmap 具备稳定的二维画布浏览模型：小内容默认双向居中，大内容可通过双向滚动条和触控板完整访问，缩放独立于编辑器字号并保持锚点稳定。所有屏幕交互共享一个通用视口快照，且 `ui`、`app` 与 mmap 之间保持纯数据边界。
