# mmap 父子节点横向间距设计

## 目标

将 mmap 画布的横向布局从“按深度对齐的列距”改为“每条父子边缘之间的固定间距”。根节点到一级节点的间距为 35dp，一级到二级及更深层级的间距为 25dp。

## 背景

现有 `level_indent` 以每层卡片左边缘的推进距离定义横坐标，并为本层最长卡片额外保留连接线空间。这会使真实的父节点右边缘到子节点左边缘的距离随标题宽度变化，参数名称和视觉效果不一致。

## 设计

主题几何参数改为两个明确的边缘间距：

- `root_child_gap`：根节点到一级节点的固定间距，默认 35dp。
- `nested_child_gap`：一级到二级及更深层级的固定间距，默认 25dp。

布局递归不再预先计算同深度的统一 x 坐标。每个子节点的左边缘由其父节点的右边缘和对应间距直接计算：

```text
child.x = parent.x + parent.width + parent_child_gap(parent.depth)
```

根节点使用原有起点。一级节点使用 `root_child_gap`；其余节点使用 `nested_child_gap`。同一深度的节点不再强制左对齐，以保证每条父子关系的可见边缘间距恒定。

连接线端点和转折点继续从实际节点坐标推导，命中图、内容边界和视口适配无需引入 mmap 专用状态。

## 配置与兼容性

主题文件暴露 `mindmap.geometry.root_child_gap` 和 `mindmap.geometry.nested_child_gap`，并应用非负约束。旧的 `level_indent` 配置不再参与布局；本次调整不修改节点尺寸、纵向同级间距、缩放或连接线样式。

## 验证

新增布局回归测试，使用不同宽度的根、一级和更深层节点，断言：

1. 根节点右边缘到一级节点左边缘为 35dp。
2. 其余父子节点的边缘间距均为 25dp。
3. 宽标题不会改变上述间距。

现有 mmap 画布测试与 markdown crate 测试继续运行，确保渲染和交互基于新坐标保持正常。
