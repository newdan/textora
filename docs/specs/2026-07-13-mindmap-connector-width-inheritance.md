# 思维导图拖拽预览连线宽度

## 问题

普通父子连线会根据子节点深度使用 5/3/2/1dp 的起始宽度。拖拽预览引导线却将深度硬编码为一级，导致挂到普通节点时仍按 5dp 绘制，与放下后生成的真实连线不一致。

## 目标行为

- 普通连线继续使用现有 5/3/2/1dp 层级规则。
- 拖拽预览根据目标父节点深度，使用与放下后真实连线相同的起始宽度。
- 挂到根节点时预览线为 5dp；挂到一级、二级及更深父节点时分别为 3dp、2dp、1dp。
- 无法从布局解析目标父节点时，预览线安全回退到 1dp。
- 保留现有圆角路径、缩放行为、颜色和拖拽反馈。

## 实现边界

修改 `crates/markdown/src/mmf/canvas.rs` 中的拖拽反馈渲染，不向布局层或拖拽协议增加状态。通过预览的 `target_rect` 查找目标父节点，以 `parent.depth + 1` 复用普通连线宽度计算。

本次不调整主题配置、节点布局、连线几何路径或 UI/app 分层。

## 测试

先加入失败测试，覆盖挂到一级父节点的预览线为 3dp、而不是硬编码的 5dp。修复后运行该定向测试、`textora-markdown` 相关画布测试及编译检查。
