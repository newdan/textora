# notora 沉浸式窗口

## 视觉约定

- 保留已有暖色主题及橙色强调色，不修改共享主题的颜色定义。
- 标题栏与左侧导航使用 `ApplicationTheme::window_surface`，同色衔接，不添加横向分割线。
- 中栏使用较浅的 `navigation_surface`；右栏头部、工具栏和正文统一使用 `editor_surface`。
- 中栏与右栏共享一个 16 逻辑像素的圆角外轮廓，两栏内部仍为直线分界；右边和底部保留 4 逻辑像素的外壳留白。左栏隐藏时左边同样保留留白。
- 普通 Windows 窗口绘制四边 1 个物理像素的 `strong_border`，并启用系统窗口阴影；最大化时隐藏客户端边框。

## 交互与平台

Windows 使用应用绘制的标题栏，高度为 36 个逻辑像素。支持拖动、双击最大化或还原、最小化、最大化或还原、关闭，以及普通窗口的八方向边缘缩放。

标题使用 Segoe UI、16 逻辑像素、半粗体和主题主文字色。左栏展开／收起按钮位于标题后方，与实际文字宽度之间保留 8 逻辑像素间距，使用圆角矩形及左分栏图标；三栏模式切换持久化的左栏状态，窄窗口切换临时导航浮层并保留当前正文。弹窗打开时禁用该按钮。

标题栏的尺寸随 DPI 缩放；产品三栏、分栏拖动区域和弹窗统一在标题栏下方布局。内容区开始的拖动跨入标题栏时，移动与释放事件继续交给原内容控件。窗口关闭沿用现有保存与退出流程。

其他平台继续使用已有原生窗口装饰，本次不改变其标题栏行为。

## 边界

`ui::window_frame` 只接收标题、窗口矩形、DPI、原生/普通/最大化状态及导航按钮可用状态，输出绘制命令和操作意图。notora 应用层执行 winit 操作及导航状态切换，窗口组件不访问笔记或运行时模型。

`ui::rounded_surface_frame` 只接收共同内容矩形和圆角半径。正文与滚动条先绘制，圆角轮廓随后绘制，菜单、对话框和紧凑导航浮层位于其上方。

编辑器头部可以接收纯颜色背景输入；默认行为保持兼容，由 notora 将其映射为编辑器底色。
