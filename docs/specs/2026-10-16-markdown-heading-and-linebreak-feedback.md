# Markdown 标题输入与段内换行反馈

## 标题状态

- ATX 标题前缀后输入空格，光标进入内容区域后隐藏前缀；只有显式移动到前缀内部时才显示源码标记。
- 空标题显示对应级别的淡色占位文字，使用标题字号、字重和行高。占位文字只参与绘制，不进入文档、选区或源码映射。
- 继续输入后占位文字消失；输入法组合期间不绘制占位文字。
- 空标题的插入点位于当前源码行末、换行符之前，不能落入下一行。
- 标题末尾 Enter 创建正文段落；内容起点 Backspace 移除标题前缀，保留现有原子编辑事务。

## Shift+Enter

- 普通段落继续保存反斜杠加换行的 Markdown 硬换行语法。
- CommonMark 在块末尾会把该反斜杠当作字面文本。编辑布局需要恢复硬换行的空白续行，隐藏反斜杠，并让续行归属原段落。
- 空白续行使用段内行距，不能额外生成独立空段落。空段落归属判定同时识别原始解析树和恢复后的投影，确保 Backspace 一次移除整条硬换行。
- 保留列表、引用、嵌套容器和 CRLF 的源码前缀与光标映射。
- 不处理代码块、行内代码、标题中的字面反斜杠或成对转义反斜杠，不改变普通预览解析规则。

## 验证

先以编辑视图测试复现标题前缀无状态反馈和段末反斜杠可见，再修复布局与投影。回归覆盖一至六级标题、不同 DPI、标题后接正文、光标点击往返、Enter/Backspace、容器续行、字面反斜杠和代码内容。
