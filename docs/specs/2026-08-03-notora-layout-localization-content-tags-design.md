# Notora 固定三栏、中文界面与正文标签设计

## 目标

修复空状态文字跨栏问题；让左栏和中栏保持用户配置的固定宽度，右侧编辑区占用剩余空间且不小于最小宽度；将 Notora 可见界面文案改为中文；将标签唯一真源从手工元数据操作改为正文中的 `#标签`。

## 布局契约

- 状态组件必须按实际字体 shaping 结果居中，所有绘制命令限制在组件矩形内。
- 三栏模式所需宽度为：当前左栏宽度 + 两个分隔条 + 当前中栏宽度 + 编辑区最小宽度。
- 进入三栏模式后，左栏和中栏不得为适配窗口而缩小，右栏使用全部剩余宽度。
- 原生窗口最小内容尺寸使用默认左栏、默认中栏、两个分隔条和编辑区最小宽度之和；高度沿用现有最小高度。
- 恢复的栏宽仍按既有范围校验，用户拖动后的宽度继续持久化。

## 中文界面

- 导航、搜索、空状态、工具栏、确认弹层、保存冲突、外部文件状态和设置页可见文案全部使用中文。
- `TXT`、`MD`、`MMAP.MD` 等文件格式标识保持原样。
- 图标资源 ID、测试夹具、内部诊断键和代码类型名不属于界面文案。

## 正文标签语法

- 标签以 `#` 开始，`#` 必须位于正文开头或非标签字符之后。
- `#` 后必须立即跟标签字符；空白开头的 Markdown 标题（例如 `# 标题`）不产生标签。
- 标签字符包含 Unicode 字母、Unicode 数字、`_` 和 `-`。
- 标签在遇到空白或其他标点时结束；同一正文中的重复标签只保留一次。
- 标签名称使用现有 Unicode 规范化规则去重，展示名保留首次解析到的规范化文本。

## 保存与索引数据流

```text
编辑器保存成功
  -> 后台索引 worker 扫描已变更文件
  -> 从正文提取标签名称集合
  -> Catalog 事务中创建缺失标签并替换 note_tags 集合
  -> 删除不再被任何笔记引用的标签
  -> 刷新全文搜索标签字段
  -> 重建左栏导航树与当前卡片查询
```

初次工作区扫描和外部文件变更扫描走同一条路径，因此标签不会依赖某一个编辑器入口。星标仍是独立用户元数据。中栏不再提供标签创建、改名、添加或移除按钮；标签浏览继续通过左栏稳定 `TagId` 节点映射到 `NavigationScope::Tag`。

## 测试

- 状态组件：长中文说明的文本绘制起点和裁剪范围不越过组件矩形。
- 三栏布局：当前栏宽参与阈值计算，三栏模式严格保留两栏宽度，右栏不小于最小值。
- 中文化：渲染模型和各工具栏/弹层断言中文文案。
- 标签解析：中文、ASCII、重复、Markdown 标题、相邻标点和无效 `#`。
- Catalog：整集合替换、自动建标签、移除旧关联、共享标签保留、孤立标签清理。
- 扫描：正文变化后标签与全文搜索、导航树同步更新。
