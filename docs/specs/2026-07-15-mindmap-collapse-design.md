# 思维导图节点展开、收起与拖拽预览设计

## 目标

为 MMF 思维导图提供非根节点的展开与收起能力。折叠状态必须持久化到 MMF 源码；折叠节点显示完整后代数量。拖拽预览必须显示被拖节点的文字，并始终以收起形态表达该子树。

## 范围

- 非根、且存在后代的节点可展开或收起。
- 根节点始终展开，既不显示控件，也不能被写为折叠状态。
- 折叠状态写入节点的 `toml node` 属性块中的 `collapsed` 字段。
- 折叠后显示完整后代子树总数，而不是直接子节点数量。
- 拖拽预览显示节点标题和后代数量，不显示后代卡片、连接线或展开控件。

不包含键盘快捷键、批量折叠、自动展开落点以及根节点折叠。

## 交互设计

### 折叠控件

每个非根、非叶节点有一个圆形控件：

- 展开时显示 `-`，点击后收起。
- 收起时显示 `+`，点击后展开。
- 控件默认不绘制；指针位于节点卡片或控件命中区域时绘制。
- 控件位于该节点出向连接线的共享转折点：横向在节点右缘与下一层节点列之间的中点，纵向与该节点中心对齐。

控件命中区域始终存在，即使其视觉内容未绘制。这使指针可以从卡片平滑移动到控件，而不会因悬浮状态切换造成闪烁。控件区不会触发标题编辑、节点选择或节点拖拽。

### 节点悬浮反馈

当指针位于节点卡片内时，该节点显示轻微背景提亮，并以主题的 `connector_hover` 颜色描边。该反馈只作用于卡片本身，不改变布局尺寸、选中状态或拖拽语义；指针离开卡片后立即恢复原有节点样式。控件区域单独触发控件显示，但不会使其所属节点进入悬浮样式。

### 折叠后的节点内容

已收起且存在后代的节点显示 `标题 · N`，其中 `N` 是完整后代子树的节点总数。计数不受后代节点自身折叠状态影响。展开节点只显示标题。

### 拖拽预览

从节点卡片空白区域发起的拖拽保持现有语义。预览卡片：

- 使用被拖节点的标题及完整后代数量。
- 始终按收起形态呈现，即使源节点当前展开。
- 不绘制 `+/-`、后代卡片或后代连接线。
- 保持现有半透明源子树和落点指示反馈。

拖拽候选仅来自当前可见节点。隐藏后代不可成为落点；收起节点可作为父节点接收“最后一个子节点”落点，但放置后保持收起，不自动展开。

## 数据与源码事务

`NodeProps.collapsed` 已存在，但节点模型尚未记录属性块及属性值的精确源码位置。解析器需要为每个节点补充用于结构化写回的属性源码元数据，至少能区分：

- 没有 `toml node` 属性块；
- 有属性块但没有 `collapsed`；
- 有 `collapsed = true/false` 的值范围。

切换时生成单个局部编辑事务：

1. 有 `collapsed` 字段时，仅替换布尔值。
2. 有属性块但没有该字段时，在该 TOML 块内插入字段。
3. 没有属性块时，在节点标题后、正文和子节点之前插入最小属性块：

   ````toml
   ```toml node
   collapsed = true
   ```
   ````

根节点的切换请求必须被拒绝，作为防御性保证。

## 布局、渲染与命中

布局递归遇到收起的非根节点时停止遍历其后代。隐藏节点不产生布局节点、连接线、命中几何或拖拽候选。因此内容边界会自然收缩，不保留空白区域。

可见布局节点必须持有其完整 AST 中的 DFS 索引。现有渲染、命中和拖拽逻辑通过该索引访问原始节点，不能再假定布局数组下标等于完整 DFS 下标。

命中图新增折叠控件几何；画布点击协议新增通用的画布控件激活结果。应用层接到该结果后转发给插件，由插件构造并执行上述编辑事务。该协议不暴露 `MindmapView` 或 `Node` 等 app 层状态，保持 UI 与应用层解耦。

## 测试策略

- 布局：收起隐藏所有后代及连接线，内容范围收缩；展开后恢复；根始终展开。
- 计数：统计完整后代子树，且不受内部折叠状态影响。
- 源码事务：替换已有字段、向已有属性块插入字段、创建新属性块，以及拒绝根节点切换。
- 命中与悬浮：控件仅对非根非叶节点存在；卡片或控件区域悬浮时显示；控件点击不进入编辑、不选中节点且不发起拖拽。
- 节点悬浮：卡片悬浮时使用 `connector_hover` 描边和轻微提亮；控件区域悬浮只显示控件，不提亮卡片。
- 拖拽：预览绘制标题和完整后代数；预览不绘制控件或后代；隐藏节点不能作为落点；落入收起父节点后不自动展开。

## 验收标准

用户可以通过连接线转折点上的 `+/-` 持久化切换任意非根、非叶节点。收起后画布只保留该节点，文本显示完整后代数量。重新解析同一 MMF 文件后状态不变。拖拽任意节点时，浮层清楚显示该节点标题及其完整后代数量，并且视觉上始终为单张收起卡片。
