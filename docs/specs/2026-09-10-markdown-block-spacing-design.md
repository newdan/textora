# Markdown 块间距统一设计

## 目标与证据

解决分割线上下间距不一致，并让全文布局、惰性布局、编辑重排和点击定位共享同一套间距结果。

已用正文、隐藏空行、分割线、隐藏空行、正文的最小样例复现：行高 24px 时线上下距正文行框分别为 24px、12px；行高 48px 时为 36px、12px。诊断断言失败，现有 horizontal_rule 相关 9 项测试通过。惰性布局物化与全文布局在该样例中一致。

根因是正文先推进段后间距，分割线又把上下间距放进自身高度。正文段后距随行高增长，分割线间距直接使用固定值。现有测试只检查分割线在自身块内居中。

本方案已实施。像素复现基于测试主题和布局行框，并非对截图原始 Markdown 或字形边缘的测量。实施细节与验证证据见文末及对应实施计划。

## 方案选择

| 方案 | 收益 | 局限 |
| --- | --- | --- |
| 调整分割线绘制位置 | 改动少 | 布局占位、点击区域和实际线位置不再一致，无法修正总高度和邻接规则 |
| 在分割线分支抵扣前块间距 | 可局部消除重复留白 | 需同步重排入口补偿；字号变化、后继块、连续分割线仍需额外规则 |
| 统一相邻块边界间距计算 | 一处表达间距规则，各路径复用 | 需要分阶段迁移布局与交互几何，推荐采用 |

## 1. 间距的所有权

将三种空间明确区分：

- 内容尺寸：文字行框、分割线线条、代码块或引用块含内部 padding 的外框。
- 块间留白：相邻兄弟块之间的一条边界，由父级块流布局器计算一次。
- 可编辑空段落：源码明确产生的真实 Paragraph，正常参与布局，不参与隐藏分隔空行的折叠。

代码块和引用块的内部 padding 保留在自身尺寸中；容器外距由父级处理，子块间距在容器内部处理，禁止跨容器折叠。

块内容排版返回内容几何，不再自行修改全局 y 来添加外距。相邻边界计算输出实际间距；放置与重排共享规则，调试读取已发布的相邻内容几何。

首块前与末块后的空间使用显式文档边界策略。迁移期间保留现有文首标题、文末滚动留白等行为，不能把文末余量误算为块内容高度。

## 2. 相邻边界规则

提供纯函数 `resolve_block_gap(previous, next, style)`。输入是 Markdown 布局层的块语义与样式，不访问应用状态。

基础规则取相邻需求的较大值；紧凑列表、连续标题等语义例外集中在该函数中，不能散布在块排版分支或增量重排入口。

以下符号表示解析后的实际像素值：P 为正文段间距，R 为分割线分隔间距，I 为列表项间距，G 为列表组间距，Ht/Hb 为标题对应级别的前后距。

| 相邻内容 | 边界间距 |
| --- | --- |
| 正文 → 正文 | P |
| 正文 → 分割线 | max(P, R) |
| 分割线 → 正文 | max(R, P) |
| 分割线 → 分割线 | R |
| 标题 → 分割线 | max(Hb, R) |
| 分割线 → 标题 | max(R, Ht) |
| 同一紧凑列表组的项 → 项 | I |
| 列表组 → 分割线 | max(G, R) |
| 分割线 → 列表组 | max(R, G) |

分割线将列表视为一组内容，用组边界距离，不使用内部项间距。其他已有块组合迁移时先用特征测试锁定，再将当前规则搬入统一函数；不顺带重新设计全篇段落、标题排版。

正文双侧必须都参与规则：只把线上方改成 max(P, R)、下方仍用 R，在大字号下依然不对称。相同普通正文夹住分割线时应保证两侧相等；标题与正文夹住分割线时允许按各自语义留白，不强求不同块的距离相同。

首个块间空源码行继续作为隐藏分隔符。多余空行保持独立可编辑段落，其内容行高不能被 max 合并吞掉。正文空段落前后按正文规则处理。

## 3. 几何与交互

分割线内容高度仅包含线宽，上下外距由边界模型提供。渲染直接消费最终线条几何，不再以包含外距的块高反推线的位置。

绘制内容范围与交互分配范围明确区分，但由同一次布局生成：

- 文本点击继续使用现有源码投影。
- 分割线保留原子源码范围，能够通过附近留白点选，交互区域不能缩为只有线宽。
- 相邻内容之间的留白按中点划分到前块末尾、后块开头，延续结构间距的源码边界语义；区域不能重叠导致命中不确定。
- 分割线自身及其分配到的附近区域映射到标记起止位置，可激活源码显示。
- 真实空段落优先使用自己的行几何和源码锚点，不能被分割线扩大后的交互区域遮蔽。

FlatLine、SourceProjectionIndex、选区、滚动定位与调试覆盖层消费布局发布的几何，不各自计算另一套补偿。

保留公共 LaidOutBlock 字段形状。实现复用现有内容矩形、源码范围和惰性布局槽位，无需新增边界附属结构；不让 ui 依赖 app。

## 4. 增量布局

估计、精排与编辑重排共享内容测量及边界解析。块高仅表示内容高度，内容起点已包含前边界放置结果；邻接边界依赖由源码块语义获得，不再以含义混合的高度字段推断外距。

块高度变化时，传播该块高度差；块类型、编辑呈现状态或邻接关系变化时，重算其前后两条边界，再把净位移传递给后续块。插入、删除和列表分组变化须覆盖受影响的邻接边界。

边界所需的块语义从结构树和显式编辑状态获得，不依赖前一个块是否已物化。删除入口处“先减再加”的镜像间距逻辑；调试显示读取已解析结果，不重新计算预期间距。

分割线展开成源码文本后仍保留分割线块语义及其外距规则，只有内容尺寸切换为源码行框。收起后必须恢复相同布局；内容高度改变造成的位移是正常重排，不通过冻结高度隐藏。

## 5. 单位规范

主题固定尺寸按逻辑像素声明，在构建本次渲染样式时乘 DPI 一次。依赖字号和行高的比例尺寸，使用已经缩放的字体指标计算，不重复乘 DPI。

分割线间距和线宽适用该规则。保留固定逻辑间距配置，不引入第二套等价配置项；相邻正文变大时由 max(P, R) 保证分割线两侧同步增长。

所有布局计算保留浮点值，最终描画按统一像素对齐策略处理。对齐只能影响栅格化，不能反馈成逐块累计的布局位移。

## 6. 实施阶段与验证

各阶段作为独立子任务；实现时进一步控制每个子任务修改范围。

1. 补齐行为测试：上下正文、连续分割线、标题/列表/代码/引用/表格邻接、文首文末、隐藏空行与真实空段落。以当前行为建立非目标组合的基线。
2. 建立统一边界解析与内部几何产物，迁移全文布局和惰性布局消费路径，移除重复外距推进及逆向补偿。
3. 接通点击、源码展开、选区、滚动和调试显示，共用边界几何；统一分割线固定尺寸的 DPI 解析。
4. 完成输入往返与性能验证，清理旧逻辑并更新旧测试中把外距包含在分割线块高内的断言。

验收条件：

- 相同普通正文夹住分割线时，以上下正文行框到线条边缘的距离比较，两侧相等；字形墨迹边缘不作为布局不变量。
- 行高与字号分别变化，在 1×、1.5×、2× DPI 下验证逻辑尺寸一致、没有重复缩放；像素描画误差使用明确的小容差。
- 全文、首次物化、精排、编辑更新、滚动淘汰后重新物化的最终位置及总高度一致。
- 激活与收起分割线后布局可往返；点击线条和上下留白始终返回合法源码位置。
- 添加或删除额外空段落只改变应有的段落占位，不遗留 y_delta；覆盖 LF、CRLF。
- 非分割线块的既有间距行为由基线测试约束，任何变化需要明确说明。
- 使用已有长文档编辑基准检查局部重排，不能因统一规则退化成每次输入重新排全文。
- 运行 textora-markdown 全库测试、编译与格式检查，重大修改完成后运行 ./scripts/verify.sh。

## 7. 实施记录

- `layout/spacing.rs` 集中块语义、相邻规则、文档边界和列表项内部边界；`layout/block.rs` 区分块流放置与已知内容起点排版，惰性精排不再恢复前驱状态或预扣间距。
- 分割线绘制、附近留白点选、源码展开与收起共享内容几何。调试覆盖层按惰性布局原始槽位读取边界，覆盖未物化前驱和内部稀疏槽位。
- 编辑、预编辑、预览与小说样式路径显式传入 DPI；样式缓存键覆盖几何及绘制输入，主题间距变更可正确失效。
- 独立 sol 子 agent 完成实现、行为测试和复审；复审发现的稀疏调试覆盖层问题已补回归并修复，复审无剩余重要问题。
