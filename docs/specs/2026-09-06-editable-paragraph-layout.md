# 可编辑空段落统一布局

用户已确认：空段落直接参与布局，光标、输入、IME和命中共用几何，替换重复补偿与邻接反推。

## 数据模型

增加 MarkdownDoc::build_for_editing(parsed, style, source)。解析器与存储格式不变；对编辑模式的布局块树后处理，插入普通 Paragraph 节点。节点具有零宽源码范围、一条空 text_line 和 ProjectedText::direct("", source_byte)。估计布局和精排均沿用现有 Paragraph 路径。

源树范围决定容器归属，不能由上一条文字的样式或屏幕位置推断。代码、metadata、表格已有内容不另造段落。顶层空行由顶层消费，引用/列表内部间隙由其内部消费，每段空行只能有一个所有者。

布局构建与源码编辑共用 EditableParagraphMap：记录每个空行串的容器、真实续行前缀来源、物理行范围、可编辑锚点与隐藏分隔。源码编辑使用最新源码的无样式结构树，不依赖上一次绘制的布局缓存。输入文字时保留该槽位，并补足新段落需要的隐藏分隔；不能只扫描连续换行字节而忽略空格和引用标记。

带缩进或引用标记的空行输入后允许使用容器的规范续行前缀。删除最后一个字须恢复相同归属、段落数量和几何；原始空白字节由 Undo 历史恢复，不能要求无历史 Backspace 猜回原来的空格写法。

## 空行语义

- 文中块间首个空源码行隐藏，其余是可编辑段落。
- 文首空行和完全空文档形成可编辑正文段落。
- 文末两条及以上空源码行的第一条隐藏，其余是正文段落；只有一条终止空行也按正文段落显示，与当前输入增强补足段边界后的布局一致。
- 空段落使用所属容器的普通段落样式。容器外不继承前标题字号或列表/代码缩进。
- Backspace 每次移除最近的可编辑空段落；还有前一空段落时停在那里，不能跳过剩余空行直接回到前块。

## 统一产物与清理

空段落进入正常 LaidOutBlock / FlatLine / SourceProjectionIndex，保持零 grapheme 锚点。所有光标和IME几何读取实际 FlatLine。隐藏分隔符只参与源码折叠，不占独立光标行。

删除 LazyLayout 的额外空行 y_delta、嵌套 reserve、对应去重集合及 view 空行高度/字号反推。SourceLineMap 继续提供源码行与空行run查询，主编辑链不再依赖其几何反推。

不增加元素专属的光标偏移。不让 ui 依赖 app 状态。不改纯预览与小说模式的块构建。
