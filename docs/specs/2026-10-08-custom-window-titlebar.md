# 跨平台自定义窗口标题栏

## 布局

侧栏模式继续使用内容区顶部的 `TitleBarWidget`，汉堡按钮由侧栏组件绘制和处理。标签页模式在标签栏上方使用同一个 `TitleBarWidget`，左侧汉堡按钮切换到侧栏模式。文件名、路径、视图切换、目录和思维导图按钮使用相同的纯数据输入，两种视图的内容区高度都包含标题栏。

## 平台窗口能力

macOS 保留系统窗口边框和红黄绿按钮，两个视图都启用透明的全尺寸标题栏。UI 在左侧预留原生按钮空间，不接管它们的命中。Windows 创建无系统装饰窗口，在标题栏右侧绘制最小化、最大化或还原、关闭按钮；空白处调用 winit 的窗口拖动能力。窗口边缘使用 winit 的系统调整尺寸能力。Linux 保留原生窗口装饰。

窗口管理操作只由应用层执行。`ui` 层只产出 `TitleBarAction`，不访问窗口或应用状态。关闭按钮与系统关闭事件复用同一保存和退出路径。

## 验证

标题栏单元测试覆盖按钮占位、命中、汉堡按钮、拖动区域与 macOS 原生按钮留白。应用层需验证标签页和侧栏模式的内容区偏移与事件路由。Windows 交互仍需在 Windows 实机检查系统缩放、最大化和贴靠行为。
